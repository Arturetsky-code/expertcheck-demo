# ExpertCheck Core 2.4 — Sprint 2 Alpha 1

Первая реализация универсального **консолидированного реестра проекта**.

## Основные изменения

- независимые источники: ПЗ, генеральный план, разделы ПД и XML;
- `Register Reconciliation Engine` объединяет источники по точной позиции и однозначному совпадению имени;
- выявляются позиции, присутствующие на генплане, но отсутствующие в ПЗ;
- выявляются конфликты наименований и физического количества;
- добавлены Project Profiles и подключаемые Knowledge Packs;
- Core не содержит условий для ДСК, ККВ, ПАС или иной отрасли;
- интерфейс показывает отдельную матрицу консолидированного реестра.

## Новые файлы

- `core/register_reconciliation.py`
- `core/project_profiles.py`
- `knowledge/profiles/*.json`
- `knowledge/packs/*/manifest.json`
- `tests/test_register_reconciliation.py`
