# ExpertCheck 10.0 Alpha 4 — Evidence Semantics & Finding Qualification

- Semantic Evidence Matcher: promotion of candidate evidence only after metric, unit, scope and semantic-context checks.
- Unit normalization strengthened for annual capacity forms such as «тыс. тонн в год».
- Entity/Metric Scope Graph: PROJECT → SITE → COMPLEX → OBJECT → EQUIPMENT → ROOM.
- Finding Qualification 2.0: PROJECT_FINDING / REVIEW_QUESTION / SYSTEM_LIMITATION.
- Report Noise Gate: system limitations do not enter the GIP action plan.
- Presentation Dictionary 2.0: Russian labels for service statuses, evidence states and technical headers.
- Normative Golden Pack 1.0 framework added. Official document sources can be verified independently from clause-level curation; no clause is treated as verified until curated.
