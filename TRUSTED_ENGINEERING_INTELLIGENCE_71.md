# ExpertCheck 7.1 Alpha 1 — Trusted Engineering Intelligence

Основная задача релиза — снизить количество ложных объектов и сделать каждый вывод проверяемым.

## Object Gate 2.0
- финальный жёсткий фильтр после всех извлекателей;
- даты не допускаются как позиции генплана;
- элементы содержания, оглавления и нумерованные заголовки разделов блокируются;
- служебные записи с нулевой уверенностью вообще не показываются в мастере состава;
- AI автоматически анализирует неоднозначные кандидаты до построения итогового реестра;
- до 24 спорных кандидатов за один пакетный AI-анализ;
- проверенные решения пользователя можно сохранять в Learning Pack и подключать в следующих сессиях.

## Digital Object Passport 2.0
- подтверждение объекта по разделам;
- матрица ТЭП по ПЗ/ПЗУ/АР/ТХ/ИОС/ПОС/ООС;
- ожидаемые и отсутствующие характеристики по типу объекта;
- связанные межраздельные риски и сценарии замечаний ГГЭ.

## Evidence Graph
Сохраняется компактная цепочка: объект → характеристика → значение → источник → межраздельная проверка.

## Remark Learning Engine
Межраздельные результаты сопоставляются с нормализованными сценариями ранее полученных замечаний с учетом параметра и повторяемости.

## Normative Knowledge Layer
Добавлен отдельный слой нормативной базы. Непроверенные записи не объявляются действующими автоматически: выводится статус «Требует проверки актуальности».

## Learning Pack
В Настройки → Knowledge Engine можно выгрузить проверенные пользовательские решения в JSON и подключить их в следующей сессии. Одно решение не создаёт глобального правила; детерминированная блокировка применяется только после повторяющихся одинаковых исключений.
