# ExpertCheck Studio 1.0 Alpha 1

Новая рабочая оболочка ExpertCheck с упрощённой навигацией, инженерным дизайном и разделением рабочего/аналитического режимов. Ядро анализа сохранено на уровне Core 3.0 Alpha 4.

## Основные страницы
- Обзор
- Документы
- Объекты
- Сверки
- Замечания

## Запуск
```bash
streamlit run app.py
```

## Studio 2.0 Alpha 4

Добавлено рабочее пространство «Комплектность»: базовые матрицы состава ПД для капитальных и линейных объектов, автоматическое определение загруженных разделов, пользовательские решения по отсутствующим разделам и обязательное подтверждение состава проекта.

## Core 3.0 Alpha 5 — Object Semantics

Добавлена защита реестра от имён файлов и служебных строк, классификация типов объектов и матрица применимости инженерных характеристик. Межраздельная сверка теперь нормализует исторические коды мощности и персонала и учитывает применимость параметров к типу объекта.


## Studio 2.0 Alpha 5 / Core 3.0 Alpha 6

- жёсткое разделение документов и объектов проекта;
- строки состава ПД, содержания, ИРД и ведомостей документов не могут создавать объекты;
- безпозиционный кандидат включается только при сильном объектном основании или подтверждении двумя независимыми разделами;
- расширено извлечение мощности, производительности, высоты, этажности, объёма и количества;
- применимость ТЭП определяется по типу объекта;
- добавлены регрессионные тесты ложных документов и неплощадных характеристик.
