# ExpertCheck Core 2.2 Alpha 1

Переходная версия инженерной платформы предэкспертной проверки проектной документации.

## Новое в версии

- добавлена инженерная база доказательств из 10 комплектов замечаний Главгосэкспертизы;
- импортировано 1 254 записи без привязки ядра к конкретной отрасли;
- добавлен классификатор типов нарушений;
- замечания отделены от исполняемых правил;
- результаты межраздельных проверок обогащаются количеством аналогичных подтверждений;
- добавлена объяснимая оценка инженерного риска;
- на обзоре отображается объём подключённой базы знаний;
- добавлены архитектурные решения ADL-003 и ADL-004.

## Важно

Инженерный риск не является статистической вероятностью получения замечания. Он отражает сочетание результата проверки, приоритета правила и количества подтверждений в базе знаний.

## Развёртывание

Загрузите содержимое папки в корень GitHub-репозитория. Главный файл Streamlit: `app.py`.
