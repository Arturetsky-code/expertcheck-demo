# ExpertCheck Core 2.0 Alpha

Первая модульная редакция ядра ExpertCheck. Рабочий интерфейс предыдущей версии сохранён, но анализ запускается через совместимый конвейер Core 2.0.

## Что добавлено

- `core/table_engine.py` — классификация инженерных таблиц по расширяемому каталогу.
- `core/semantic_engine.py` — сопоставление объектов с приоритетом позиции по генплану.
- `core/rule_engine.py` — основа движка правил, отделённого от интерфейса.
- `core/confidence.py` — объяснимая оценка уверенности по факторам.
- `core/catalogs.py` — подключение универсальных и отраслевых Knowledge Packs.
- `knowledge/core` — каталоги объектов, характеристик, таблиц и универсальных правил.
- `knowledge/packs/corporate/checklists` — правила, импортированные из чек-листов Генплана, АД и ТХ.
- `knowledge/packs/mining/remarks` — первый структурированный набор замечаний ДСК как обучающий пример, а не ограничение ядра.

## Архитектурный принцип

Код выполняет чтение, извлечение, сопоставление и проверку. Состав проверок, отраслевые и корпоративные знания хранятся вне кода в JSON-каталогах.
