# ExpertCheck 6.2 Alpha 1.2 — Registry & Report Integrity Hotfix

## Исправления

- значения, похожие на календарные даты (`21.05.26`, `21.05.2026`, `2026.05.21`), больше не принимаются за позиции генерального плана;
- проверка даты применяется при чтении генплана, структурированных таблиц, универсальных реестров и при окончательной сборке состава проекта;
- доказательства происхождения отображаются обычными полями и карточкой фрагмента, а не Python-словарём/кодом;
- все значения перед записью в XLSX очищаются от запрещённых XML-символов, вложенные структуры сериализуются, чрезмерно длинные строки ограничиваются;
- отчёты проходят проверку ZIP/XLSX и повторное открытие через openpyxl;
- техническое приложение сокращено до инженерно значимых столбцов и не содержит сырые вложенные структуры и полный текст страниц.

## Ограничение полного комплекта

Текущая версия предназначена для поэтапной загрузки комплектов. Одновременный анализ всех разделов ПД и всех отчётов ИИ в Streamlit Community Cloud пока не считается производственно надёжным из-за ограничений памяти, времени обработки, объёма загрузки и лимитов внешнего AI. Рекомендуется загрузка логическими пакетами с последующей консолидацией.
