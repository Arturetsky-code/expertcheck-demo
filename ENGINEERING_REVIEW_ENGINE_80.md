# ExpertCheck 8.0 Alpha 1 — Engineering Review Engine

Фокус релиза — инженерная логика проверки, а не новые экраны.

## Cross-Section Rules 1.0

Добавлен каталог зависимостей инженерных данных между разделами. Для каждого ключевого ТЭП задаются профильные разделы-владельцы, контрольные разделы и объяснение, почему значение должно быть согласовано.

Поддержаны: площади, строительный объём, высота, этажность, производительность, электрическая мощность, напряжение, расход, давление, диаметр, объёмы резервуаров, вместимость, протяжённость, ширина, глубина и количество.

## Normative Knowledge Base 1.0

Добавлен отдельный набор машинно-читаемых требований для предварительной предподачной проверки. Он не объявляет юридическое соответствие и не заменяет специалиста. Нормативный контекст привязывается к межраздельным проверкам и пунктам чек-листа.

## Checklist Compiler 5.0

Пункты чек-листов получают класс выполнения:

- AUTO — детерминированная проверка;
- CALC — расчётная / межраздельная проверка;
- SEMANTIC — смысловой анализ с AI;
- EXPERT — подготовка доказательств для специалиста.

В деталях пункта отображается нормативный контекст. Основная двухколоночная таблица сохранена.

## Preliminary Compliance

Межраздельная проверка дополнительно формирует предварительную оценку:

- Предварительно согласовано;
- Выявлен риск несоответствия;
- Недостаточно данных;
- Требует инженерной проверки.

Каждый вывод связан с владельцем данных, зависимыми разделами и нормативным контекстом.
