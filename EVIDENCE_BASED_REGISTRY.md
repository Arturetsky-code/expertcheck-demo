# ExpertCheck 4.2 — Evidence-Based Object Registry

Каждый объект обязан иметь структурированное доказательство происхождения: файл, раздел ПД, страницу, пункт/зону документа, таблицу и строку (если доступны).

## Запреты
Имена файлов, состав ПД, содержание, ведомости документов, титульные листы и названия разделов не могут создавать объект даже при ручном включении без другого допустимого доказательства.

## Quality Gate
Межраздельная сверка запускается только после подтверждения реестра. Включённая позиция без допустимого доказательства блокирует подтверждение.

## Решения пользователя
Для исключаемых позиций сохраняются причина и комментарий. Эти данные являются проверенными примерами для будущего Knowledge Engine, но не создают глобальные правила автоматически.
