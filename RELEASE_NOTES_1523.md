# ExpertCheck 15.2.3 — Reliability Hotfix & AI Continuation

## Что исправлено

- Агрегация атомарных требований сохраняет `adversarial_state`, адресные `verification_evidence` и причины блокировки. Категоричный родительский результат проходит Quality Gate только тогда, когда все его атомы имеют состояние `PASSED`.
- Та же политика применена к агрегации корпоративных чек-листов.
- При непройденном Quality Gate XLSX получает статус «Предварительный — Quality Gate отчёта не пройден»; итоговый статус больше не маскирует внутреннюю ошибку согласованности.
- Для строк без корректного исходного ID формируется детерминированный ID по содержимому. Значение `nan` больше не попадает в листы вопросов и подтверждённых расхождений.
- В листах AI-аудита отдельно показаны фактические отправки, восстановленные ответы и остаток очереди Critic.

## Продолжение AI-проверки

На странице результата добавлена кнопка «Продолжить AI-проверку». Повторный запуск:

1. восстанавливает точный извлечённый корпус из цифрового снимка;
2. проверяет отпечаток проекта и использует только соответствующий checkpoint;
3. повторно не читает и не требует исходные PDF;
4. переиспользует успешные ответы Judge/Critic и вызывает провайдеры только для незавершённых пакетов;
5. повторяет fail-closed контроль доказательств;
6. заново строит публичные метрики, план проверки, карту покрытия и Quality Gate.

## Политика качества

- `NOT_FOUND` по-прежнему является границей автоматизации, а не нарушением проекта.
- L5 требует адресного доказательства и пройденного локального gate; смысловой L5 дополнительно требует независимых Judge и Critic.
- Неуспешный или невалидный ответ AI не сохраняется как завершённый checkpoint.
- Исходное значение насосной станции `25 м` не исправляется автоматически и остаётся адресным вопросом о возможной десятичной запятой `2,5 м`.

## Валидация

Запуск:

```bash
python -B tools/validate_1523.py
```

Release gate включает 73 проверки, в том числе регрессию свёртки L5, статус XLSX при сбое Quality Gate, стабильные ID и продолжение анализа из снимка без исходного PDF.
