# ExpertCheck 10.1 Alpha 3 — Interactive Engineering Review

## Цель
Вернуть контролируемое участие специалиста без возврата к перегруженному интерфейсу и ускорить переход от пассивной диагностики к гибридной инженерной проверке.

## Изменения
- Рабочий маршрут: Проект → Подтверждение → Проверка → Чек-листы → Результаты → Отчёт.
- Новый компактный экран «Подтверждение»: комплектность + найденные объекты.
- Чек-листы доступны в обычном режиме.
- Добавлены ручные решения специалиста по пунктам чек-листов; автоматический результат сохраняется отдельно.
- Кандидат в доказательства переводится в вопрос специалисту, а не в автоматическое соответствие.
- Отчёт ГИПа снова содержит предметные листы по Заданию, НТД и чек-листам.
- Резюме руководителя содержит отдельную готовность проверки по трём ключевым контурам.
- Технические массивы остаются в техническом приложении.

## Принцип качества
Precision → Coverage. Ручное решение специалиста не подменяет автоматический вывод и наоборот.
