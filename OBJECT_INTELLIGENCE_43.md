# ExpertCheck 4.3 Alpha 1 — Object Intelligence

## Цель

Снизить количество ложных объектов до запуска межраздельной сверки и сделать каждое решение объяснимым без внешнего AI.

## Новая логика

1. Служебный источник блокирует кандидата.
2. Официальный объектный реестр подтверждает объект.
3. Два независимых инженерных документа могут подтвердить объект без официального реестра.
4. Одиночное текстовое упоминание остаётся кандидатом и не включается автоматически.
5. Существующие и перспективные объекты сохраняются как контекст, но не включаются в текущий состав.

## Локальный инженерный советник

Советник работает поверх структурированной модели ExpertCheck, объясняет подозрительные позиции и результаты сверки, не использует внешний API и не изменяет данные проекта.
