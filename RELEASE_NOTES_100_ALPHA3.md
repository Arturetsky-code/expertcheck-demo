# ExpertCheck 10.0 Alpha 3 — Evidence Resolution & Semantic Scope

- Централизована русификация служебных кодов в интерфейсе и XLSX: области требований, методы проверки, типы требований, качество доказательств, состояния нормативного покрытия.
- Исправлена версия приложения/отчётов.
- Applicability-aware reporting: «Недостаточно данных / не найдено подтверждение» не формирует действие ГИПу, пока не доказано, что межраздельное подтверждение действительно обязательно.
- Расширена русификация кодов показателей (продолжительность смены, объём кузова, объём ковша).
- Подготовлен слой Evidence Resolution & Semantic Scope для дальнейшего повышения покрытия Задания без снижения точности.
