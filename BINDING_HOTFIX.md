# Studio 2.1 Alpha 2.3 — Object/ТЭП Binding Hotfix

Исправлена критическая ошибка привязки ТЭП к соседнему объекту на продолжающихся страницах таблицы «Сведения о сложном объекте».

Причина: на страницах без повторной шапки таблицы общий поисковый алгоритм выбирал ближайшее название объекта и мог связать последний показатель предыдущей позиции со следующей позицией.

Исправление:
- позиционные блоки распознаются и на страницах-продолжениях;
- границы объекта определяются по следующей позиции по генплану;
- все ТЭП внутри блока относятся только к этой позиции;
- общий поиск характеристик на такой странице не запускается повторно;
- добавлен регрессионный тест для пары «Модуль обеспыливания — 23,5 м²» / «Здание проборазделки — 89,9 м²».
