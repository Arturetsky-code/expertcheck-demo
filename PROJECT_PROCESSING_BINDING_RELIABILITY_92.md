# ExpertCheck 9.2 Alpha 1 — Project Processing & Binding Reliability

Релиз стабильности и удобства предпроверки.

## 1. Загрузка и прогресс
- после передачи файлов Streamlit показывает число файлов и общий объём;
- отдельно отображается стадия «Загрузка в приложение» и отдельная стадия «Анализ проекта»;
- анализ показывает процент, текущий этап и описание операции.

Ограничение Streamlit: Python-код приложения получает UploadedFile только после передачи браузером, поэтому точный серверный byte-progress во время самой HTTP-передачи без отдельного upload-компонента недоступен. После получения файлов прогресс отражается полностью.

## 2. Режимы проверки
- Быстрая — основные разделы ПД;
- Расширенная — рекомендуется: ПД + ИИ + ключевая ИРД;
- Полная — весь комплект.
Файлы, исключённые режимом, не удаляются; пользователь может выполнить более глубокую проверку позже.

## 3. Entity–Property Binding 3.0
- введён стабильный object_id;
- ключ сравнения: object_id + parameter_code + scope;
- инженерный показатель не может стать объектом;
- если object_name совпадает с «Площадь застройки», «Мощность», «Высота» и т.п., запись исключается из межраздельной сверки;
- доказательства показываются в единой форме: «КПП · Площадь застройки — 42,5 м²»;
- позиция генплана имеет приоритет при формировании object_id.

## 4. НТД в отчётах
- Резюме руководителя: количество проверенных ссылок и нормативных рисков;
- Отчёт ГИПа: отдельный лист «Актуальность НТД»;
- Техническое приложение: полный нормативный реестр с файлом, страницей, редакцией, заменой, приоритетом и источником проверки.

## 5. Инкрементальная обработка
Добавлен фундамент file fingerprints (SHA-256) и сравнение состояний комплекта. Следующий этап сможет использовать эти данные для обработки только новых/изменённых файлов.
