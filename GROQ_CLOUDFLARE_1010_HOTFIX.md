# Groq Cloudflare 1010 Hotfix

- Для запросов к внешним AI API добавлены `User-Agent` и `Accept`.
- Ошибка Cloudflare 1010 отделена от ограничений Model permissions.
- В автоматическом режиме ошибка 1010 считается сетевой блокировкой и запускает резервный OpenRouter.
- Прямой режим Groq показывает корректную диагностику без утверждения, что проблема в API-ключе или модели.
