# Проверка размещения в GitHub

В корне репозитория должны находиться:

- `app.py`
- `analyzer.py`
- `requirements.txt`
- папка `core/`
- папка `studio/`
- папка `knowledge/`

Не загружайте в репозиторий внешнюю папку архива целиком как один вложенный каталог.
После замены файлов выполните в Streamlit Community Cloud: **Manage app → Reboot app**.
Если запуск снова завершится ошибкой, новая сборка покажет название отсутствующего модуля прямо на странице.
