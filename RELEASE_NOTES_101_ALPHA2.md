# ExpertCheck 10.1 Alpha 2 — Verification Integrity

Фокус релиза: достоверность завершённых проверок важнее покрытия.

- Checklist Verification Levels L1–L5: простой поиск наличия больше не закрывает проверки полноты и инженерного соответствия.
- Finding Continuity Gate: подтверждённый конфликт в Project Understanding не может молча исчезнуть из отчёта.
- Metric Scope hardening: площадь застройки не допускается к сущности уровня оборудования.
- Review Planner сохраняет четыре рабочих экрана и три главных контура: Задание, НТД, чек-листы.
- Принцип релиза: Precision → Coverage.
