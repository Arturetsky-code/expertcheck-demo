# ExpertCheck Studio 3.0 Alpha 1 — Project Workspace

- Навигация сокращена до пяти рабочих пространств: Проект, Объекты, Проверки, Замечания, Отчёты.
- Документы и комплектность перенесены внутрь рабочего пространства проекта.
- Добавлена постоянная панель состояния проекта.
- Главный экран показывает только ключевые показатели и результаты, требующие решения.
- Аналитический режим перенесён в скрытый блок «Дополнительно» и переименован в «Режим разработчика».
- Добавлен отдельный центр отчётов.
