# ExpertCheck Core 3.0 Alpha 4

## Основное изменение

Добавлен **Project Upload Manager** — двухэтапная загрузка комплекта проекта перед инженерным анализом.

### Поддерживаемые способы загрузки

- несколько PDF;
- PDF и XML одновременно;
- один или несколько ZIP-архивов с вложенными папками;
- смешанный вариант: отдельные документы и архивы.

### Предварительная проверка комплекта

Перед запуском пользователь видит:

- перечень найденных файлов;
- формат и размер;
- предполагаемый раздел ПД или ИИ;
- семейство раздела;
- источник файла;
- доступные проверки и ограничения комплекта.

Тип документа можно исправить вручную. Анализ запускается только после подтверждения состава.

### Защита и диагностика

- игнорируются служебные и неподдерживаемые файлы;
- блокируются небезопасные пути ZIP;
- контролируется число файлов и распакованный объём;
- удаляются точные дубли;
- выдаются предупреждения о разных шифрах и годах;
- файлы одного семейства группируются как ПЗУ, АР, ТХ, ИОС и т.д.

### Совместимость

Ручной тип документа передаётся в существующий анализатор и имеет приоритет над автоматической классификацией по имени и содержимому.
