# ExpertCheck Core 2.0 — Alpha 4

Alpha 4 переносит в новое ядро первые реальные функции структурного извлечения инженерных таблиц.

## Новое

- Table Engine учитывает тип документа и область применимости шаблона.
- Для таблиц ТЭП восстанавливаются строки «показатель — единица — значение», в том числе при переносе на соседние строки PDF.
- Semantic Engine строже учитывает позицию по генплану и значимые слова наименования.
- Добавлен Quality Engine с измеримыми показателями качества извлечения.
- В результаты страниц добавляется `table_structured_rows` для дальнейшего перехода от legacy-поиска к нативному извлечению Core 2.0.
