# ExpertCheck 9.0 Alpha 1 — Multi-User Workspace

Первый этап многопользовательской архитектуры:
- регистрация и вход по email/паролю;
- Argon2-хеширование паролей;
- личный кабинет «Мои проекты»;
- каждый проект имеет owner_id;
- чтение, сохранение и удаление проекта выполняются только с условием owner_id текущего пользователя;
- сохранение результата анализа и пользовательских решений;
- история запусков анализа;
- PostgreSQL через DATABASE_URL для постоянного серверного хранения;
- локальный SQLite только как режим разработки.

Важно: локальная файловая система Streamlit Community Cloud не является постоянным хранилищем. Для production необходимо настроить внешний PostgreSQL. Хранение исходных PDF в S3-совместимом приватном хранилище будет следующим этапом.
