# Валидация ExpertCheck 15.0 Alpha 1

Контрольный прогон выполнен на том же комплекте из 12 PDF без внешних AI-ключей.

## Результат

- Конвейер завершён без ошибок, включая Drawing Intelligence.
- Выполнено 615 проверок против 513 в 14.0 (+102).
- Адресные доказательства L3–L5 подготовлены для 345 проверок против 281 (+64).
- Доказательное покрытие выросло с 54,8% до 56,1% при одновременном расширении программы проверок.
- L4: 138 против 112; каждый пакет L4 имеет выполненный адресный контракт доказательства.
- Строго завершено L5 без AI: 2. Показатель намеренно не завышается при отключённых Judge/Critic.
- Активировано 95 исполняемых пунктов ТХ из корпоративного каталога из 97 строк (2 строки — заголовки иерархии).
- Обнаружено контрольное расхождение площади компрессорной; ошибочное значение высоты насосной станции 25 м удержано вне сравнения.
- Небезопасных автоматических закрытий специалистских/смысловых пунктов нет.
- Три XLSX-отчёта прошли проверку OOXML, русификации статусов и пользовательского подтверждения комплектности.
- В отчёте ГИПа и техническом приложении присутствуют листы AI-аудита.

## Проверка агентов и регрессия

- 16 из 16 сценариев Judge/Critic и Constraint Engine пройдены.
- 186 регрессионных тестов пройдены, 3 старых интеграционных теста пропущены из-за отсутствующих внешних файлов `/mnt/data`, ошибок тестов нет.

Машиночитаемые результаты: `VALIDATION_150_ALPHA1.json`, `VALIDATION_150_ALPHA1_GATE.json`, `AI_AGENT_VALIDATION_150_ALPHA1.json`, `REGRESSION_150_ALPHA1.json`.
