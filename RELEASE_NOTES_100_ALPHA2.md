# ExpertCheck 10.0 Alpha 2 — Directed Evidence Extraction

Основные изменения:
- Requirement-Directed Extraction для числовых требований Задания.
- Evidence Quality Gate: candidate evidence отделено от verified evidence.
- Проверка совместимости единиц измерения; запрещены ложные сравнения т/ч ↔ тыс. т/год без расчётной цепочки.
- Object Hierarchy Graph для групповых/дочерних позиций состава объекта.
- Table Semantic Scope Guard против переноса показателей площадки/проекта на дочерние объекты.
- НТД: пробел верификации помечается как пробел KB, а не как риск проекта в пользовательском отчёте.
- В отчёты добавлены качество доказательства и количество направленных кандидатов.

Ключевой принцип: совпадение числа без совпадения показателя, области действия, владельца и совместимой единицы не является доказательством.
