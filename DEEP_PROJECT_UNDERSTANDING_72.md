# ExpertCheck 7.2 Alpha 1 — Deep Project Understanding

Ключевая цель версии: восстановить полноту определения состава проекта без возврата ложных объектов.

## Новое
- Project Object Recovery: поиск состава по сильным формулировкам ПЗ, составу сложного объекта и идентификационным признакам.
- AI Project Scope Discovery: внешний AI участвует уже в первичном поиске, а не только фильтрует найденных кандидатов. AI-объект принимается только если его название дословно найдено в исходном фрагменте.
- Object Gate 3.0: даты, содержание, оглавление и пункты документа блокируются; официальный объектный ряд допускает отраслевые сокращения и короткие имена.
- PP87 Profile Engine: автоматическое определение линейного/производственного/непроизводственного профиля и признаков применимости приложений №1–10.
- PP87 Checklist Matrix 2.0: расширенные обязательные контрольные вопросы по ПЗ, ПЗУ, АР, КР, ТХ, ИОС, ПОС, ПБ и ООС.
- Historical Remark Library: нормализованная база 1362 уникальных формулировок из 2289 исторических замечаний; используется для поиска аналогий.
- Normative Evidence Index: индекс нормативных ссылок, встречавшихся в замечаниях экспертов. Историческое упоминание не считается подтверждением актуальности НТД.
- Scan Intelligence foundation: определение текстово-разреженных сканированных страниц и ограниченный OCR через PyMuPDF/Tesseract при наличии OCR runtime.
- Object Passport: детальные источники по документам, разделам, страницам и способу обнаружения.

## Принцип достоверности
Ни один AI-ответ не становится подтверждённым объектом без исходного доказательства. Категорические выводы по ПП №87 и нормативам не формируются при недостатке доказательств.
