# ExpertCheck Core 2.4 — Sprint 2 Alpha 2

Сборка усиливает консолидированный реестр проекта без отраслевой привязки.

## Основные изменения

- добавлен `Object Identity Engine`;
- позиции по генплану остаются строгим первичным идентификатором;
- записи без позиции связываются только при однозначном совпадении;
- поддержано сопоставление сокращения с полным наименованием (например, КТП);
- отдельно рассчитывается уверенность наименования;
- количество получает источник, статус и отдельную уверенность;
- конфликт количества между ПЗ и генпланом не скрывается;
- значение количества выбирается по приоритету источника, но помечается для проверки;
- в интерфейс добавлены диагностические поля идентификации и количества.

## Обновление

Загрузите содержимое папки сборки в корень GitHub-репозитория и перезапустите Streamlit-приложение.

## Core 3.0 Alpha 1 — XML Engine

- XML включается в консолидированный реестр как независимый источник.
