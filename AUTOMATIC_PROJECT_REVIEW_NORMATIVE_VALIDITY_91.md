# ExpertCheck 9.1 Alpha 1

## Automatic Project Review
- После основной классификации комплекта ExpertCheck сам определяет присутствующие разделы.
- Подходящие корпоративные чек-листы запускаются автоматически.
- Пользовательский выбор чек-листа/раздела сохранён только как дополнительный выборочный режим.
- Для SEMANTIC/EXPERT пунктов при включённом AI режиме автоматический AI-анализ запускается без ручного сопоставления раздела и чек-листа.
- Expert Practice KB подключается приоритетно к пунктам, требующим внимания.

## Normative Validity Checker
- Ссылки НТД извлекаются напрямую из текста страниц PDF, а не только из инженерных находок.
- Результаты: Действует / Действует с изменениями / Утратил силу / Заменён / Возможна устаревшая редакция / Требует верификации.
- Категоричный статус присваивается только кураторской записи реестра.
- Неизвестный документ никогда автоматически не объявляется недействующим.
- Для каждой ссылки сохраняются файл, страница, контекст и риск влияния на проектное решение.
- СП/ГОСТ/СНиП направляются на верификацию по официальным источникам строительного нормирования; НПА — по официальному опубликованию.
- Реестр исторических ссылок экспертов остаётся отдельным слоем и не считается доказательством текущей действительности НТД.

## Performance
Expert Practice index дополнительно оптимизирован: токены повторяющихся экспертных правил предварительно индексируются, что позволяет автоматически прогонять большие чек-листы без прежней задержки.
