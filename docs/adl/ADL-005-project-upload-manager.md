# ADL-005 — Project Upload Manager

## Решение

Загрузка проекта выполняется в два этапа: подготовка комплекта и подтверждение пользователем, затем инженерный анализ.

## Причины

- архивы могут содержать вложенные папки и неподдерживаемые файлы;
- автоматическая классификация разделов не всегда однозначна;
- смешение проектов и редакций приводит к ложным расхождениям;
- пользователь должен видеть ограничения проверки до запуска ресурсоёмкого анализа.

## Следствия

- Core принимает нормализованные объекты `PreparedUpload`, а не зависит от Streamlit;
- поддерживаются PDF, XML и ZIP;
- тип документа можно исправить до анализа;
- ZIP распаковывается только в памяти с защитой от path traversal и чрезмерного распакованного объёма;
- отсутствие разделов не блокирует анализ, но отражается в диагностике комплекта.
