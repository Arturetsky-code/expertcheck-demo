# ExpertCheck 10.1 — Review Planner & Verification Core

Основной пользовательский сценарий строится вокруг трёх обязательных контуров: Задание на проектирование, НТД, чек-листы. Внутренние движки (Drawing Intelligence, межраздельная сверка, Project Understanding, AI, provenance) являются поставщиками доказательств и не образуют самостоятельный пользовательский маршрут.

Ключевой принцип: сначала формируется план применимых проверок конкретного проекта, затем каждая проверка получает evidence contract, после чего выполняется специализированным checker'ом. Неудача автоматической проверки является ограничением покрытия ExpertCheck и не считается проблемой проекта.
