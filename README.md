# ExpertCheck Core 3.0 Alpha 3

Экспериментальная облачная версия системы предварительной проверки проектной документации.

## Главное в Alpha 2

- Normalization Engine для характеристик XML 01.06 и 01.07.
- Нормализация наименований показателей и единиц измерения.
- Извлечение объектов из строк ТЭП XML 01.06 с разделителем через точку и XML 01.07 с разделителем через запятую.
- Структурированные каталоги нормативов, ИРД, инженерных изысканий и состава ПД из XML.
- Первичная объяснимая сверка PDF ↔ XML.
- Защита от ложного сопоставления соседних строк больших таблиц PDF.
- Диагностика XML на странице «Обзор».

## Поддерживаемые XML-схемы

- explanatorynote-01-06.xsd
- explanatorynote-01-07.xsd

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Основной файл Streamlit Community Cloud: `app.py`.

## Ограничения

- PDF ↔ XML сравниваются только при достаточно надёжной локальной привязке значения к объекту.
- Коды единиц измерения нормализуются только для подтверждённых соответствий.
- Результаты являются предварительными и требуют инженерной проверки.


## Core 3.0 Alpha 3 — усиленная межраздельная сверка

- сводная проверка одной характеристики по всем разделам проекта;
- объединение частей АР1/АР2, ТХ1/ТХ2 и ПЗУ1/ПЗУ2 в семейства разделов;
- точная позиция по генплану является главным ключом объекта;
- выявление конфликтов внутри одного раздела;
- отдельный статус для характеристики, найденной только в одном источнике;
- матрица ожидаемых разделов используется как диагностика, а не как автоматическое замечание;
- результаты содержат все значения, страницы, документы и установленный допуск.
