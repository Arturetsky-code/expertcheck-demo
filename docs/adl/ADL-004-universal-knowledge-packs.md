# ADL-004: Универсальное ядро и подключаемые пакеты знаний

## Решение
Разделять знания на:
1. универсальное ядро;
2. отраслевые пакеты;
3. корпоративные пакеты;
4. фактические доказательства из проектов.

Загруженные проекты используются для выявления универсальных закономерностей и регрессионного тестирования, но не ограничивают область применения ExpertCheck.
