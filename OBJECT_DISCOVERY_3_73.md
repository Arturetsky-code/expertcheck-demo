# ExpertCheck 7.3 Alpha 1 — Object Discovery 3.0

Цель релиза — восстановить надёжное определение состава проектируемых объектов и исключить ситуацию, когда строгие фильтры оставляют пользователя без реальных объектов проекта.

## General Plan First

Экспликация генерального плана рассматривается как независимый опорный реестр. Поиск генплана выполняется не только по назначенному типу ПЗУ2, но и по имени файла и содержанию первых 12 листов/страниц. Позиции из экспликации не могут исчезнуть только потому, что ПЗ или XML ещё не подтверждены.

## Multi-source reconciliation

После чтения генплана система сопоставляет найденные позиции с ПЗ, XML, идентификационными признаками, составом сложного объекта и профильными разделами. Если ПЗ содержит усечённое многострочное имя, а генплан — полное наименование той же позиции, сохраняется более полная идентичность генплана.

## Recovery Mode

Если подтверждённый реестр пуст или явно неполон относительно экспликации, приложение фиксирует Recovery Mode и повторно использует сильные источники состава проекта вместо того, чтобы считать пустой результат корректным.

## AI

AI автоматически анализирует спорные кандидаты в умном режиме. Однако AI не может удалить строку официальной экспликации: при конфликте такая позиция переводится в ручную проверку.

## Критический hotfix Project Assembly

Исправлена ошибка состояния `default_include`: одна спорная позиция могла отключить автоматическое включение всех следующих надёжных объектов. Теперь решение рассчитывается независимо для каждой строки.

## Дополнительная защита

Жёстко исключаются календарные даты, элементы оглавления/содержания и названия ТЭП (`Площадь застройки`, `Общая площадь`, `Мощность`, `Объём` и др.) как ложные объекты.
