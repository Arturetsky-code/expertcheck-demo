# ExpertCheck Core 2.3 — Sprint 1 Alpha 4

Сборка посвящена повышению полноты извлечения реестра объектов и корректности физического количества.

## Основные изменения

- позиции по генплану распознаются как на отдельной строке, так и в формате `2.1.3 Наименование объекта`;
- строка объекта ограничивается следующей реестровой позицией, поэтому соседние объекты не смешиваются;
- иерархические позиции остаются самостоятельными объектами;
- количество извлекается только при явных признаках `Количество`, `кол-во`, `шт.` или `ед.`;
- площади, объёмы, производительность и коды классификатора не принимаются за количество;
- приоритет при определении количества имеют явные данные официального реестра ПЗ;
- при разных явных количествах запись получает статус `Требует проверки`;
- в интерфейс добавлены колонки `Статус количества` и `Основание количества`;
- режим инспектора сохраняет способ извлечения и причины объединения.

## Регрессионная проверка

На ПЗ ККВ сформировано 11 уникальных позиций. Для позиции `2.1.5 Противопожарные резервуары` корректно извлечено количество `3 шт.`. Повторные строки на следующих страницах объединяются по точной позиции.

Автоматические тесты: **17 passed**.

## Sprint 1 Alpha 4 — General Plan Register Engine 1.0

- ПЗ больше не является единственным источником реестра объектов.
- Из ПЗУ2 извлекается экспликация зданий и сооружений.
- Позиционные обозначения в текстовом/векторном слое поля чертежа используются как дополнительное подтверждение.
- Формируется консолидированный реестр ПЗ ↔ генеральный план.
- Объекты, найденные на генплане и отсутствующие в ПЗ, не теряются и получают отдельный статус.
- В интерфейс добавлена сверка источников и диагностика конфликтов наименований.

Ограничение текущей версии: движок читает текстовый и векторный слой PDF, но пока не распознаёт геометрию контуров и растровые чертежи.
