# ExpertCheck 15.0 Alpha 1 — Executable Verification Engine

## Что изменилось

- Добавлен числовой Constraint Engine для операторов `=`, `≠`, `>`, `≥`, `<`, `≤` и диапазонов «от … до …».
- Требуемые и проектные значения приводятся к совместимым каноническим единицам до сравнения: давление, длина, время, годовая производительность и другие поддержанные параметры.
- Уровень L4 выдаётся только адресному доказательству с совпавшими сущностью, параметром, модальностью и критическими квалификаторами.
- Judge повторно запрашивает пропущенные ответы по одному пакету; Critic запускается только для валидного категоричного решения Judge.
- В отчёты ГИПа и техническое приложение добавлены листы аудита AI: кандидаты, реальные вызовы, провайдеры, модели, ответы и причины блокировки.
- Лимит смысловой очереди увеличен до 40/60 пакетов в умном режиме и 80/120 в максимальном режиме для Задания/чек-листов.
- Подключён поставлявшийся с базой, но ранее не исполнявшийся чек-лист №14 «Технологические решения» (97 пунктов).
- В модели проекта значения теперь выводятся парами `раздел → значение`; исключено ошибочное независимое сортирование разделов и величин.
- Решения пользователя о комплектности и составе объектов передаются в формируемые отчёты.
- Расширена русификация служебных статусов и заголовков технических таблиц.

## Политика достоверности

Отсутствие доказательства не считается нарушением. Числовое несоответствие формируется только по структурированному факту с адресом источника и исполняемому проверочному рецепту; AI-консенсус не создаёт нарушение без машинно-читаемого сигнала конфликта.
