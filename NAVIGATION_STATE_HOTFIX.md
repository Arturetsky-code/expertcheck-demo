# ExpertCheck 6.0 Alpha 1.1 — Navigation State Hotfix

Исправлена ошибка StreamlitAPIException, возникавшая после завершения анализа при попытке изменить `st.session_state.page` после создания навигационного виджета с тем же ключом.

Навигация теперь выполняется отложенно через `_navigate_to` и применяется в начале следующего цикла до создания `st.radio`. Аналогично исправлен переход после сброса проекта из настроек.
