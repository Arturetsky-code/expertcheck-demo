# ExpertCheck 7.3 Alpha 1.2 — PZ Authoritative Registry Hotfix

Критическое исправление определения состава проекта.

## Изменения
- Добавлен отдельный парсер блока ПЗ «Сведения о сложном объекте … сведения о зданиях (сооружениях), входящих в состав сложного объекта».
- Этот перечень становится первичным опорным реестром, если блок реально присутствует в ПЗ.
- Парсер поддерживает многострочные наименования и переносы таблицы между страницами.
- ТЭП из той же строки ПЗ привязываются к конкретной позиции объекта с ROW_LOCKED.
- Строки из «Идентификационных признаков», отсутствующие в финальном составе сложного объекта, больше не попадают в основной реестр автоматически.
- Позиции генплана, отсутствующие в официальном составе ПЗ, сохраняются как отдельные спорные кандидаты для межраздельной проверки.
- Исправлены ложные фильтры для «Пункт обогрева», «Здание с кабинетом начальника» и слов, содержащих сочетание «том» внутри другого слова.
- Исправлено ложное определение «резервуарами» как признака перспективного/резервного объекта.
- Доказательство из официального перечня ПЗ не может быть заблокировано общим лексическим фильтром.

## Контрольный тест
На предоставленном пользователем ПЗ «Площадка дробильно-сортировочного комплекса ООО «Золото Дельмачик»» извлечено 35 позиций официального состава сложного объекта; все 35 формируют подтвержденный опорный реестр при анализе одного ПЗ.
