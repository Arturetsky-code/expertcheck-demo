# Core Quality 4.0 Alpha 1 — Trusted Project Model

## Основное изменение
Система больше не формирует рабочий реестр из любого текста, похожего на название объекта.

Каждая объектная находка проходит:
1. классификацию зоны документа;
2. запрет для состава ПД, содержания, ведомостей, титулов и имён файлов;
3. определение статуса: проектируемый, реконструируемый, существующий, перспективный, демонтируемый;
4. оценку силы доказательств;
5. разделение на подтвержденный реестр и кандидатов.

Только подтвержденный реестр используется для паспортов, ТЭП и замечаний.

## Checklist Engine 1.0
Интегрированы 15 предоставленных чек-листов — 761 контрольный пункт.
Пункты классифицированы:
- A — автоматизируемые;
- B — частично автоматизируемые;
- C — ручная инженерная проверка.

Система не объявляет ручные пункты автоматически выполненными.
