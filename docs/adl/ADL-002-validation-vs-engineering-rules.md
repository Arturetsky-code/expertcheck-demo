# ADL-002: Разделение валидации модели и инженерных правил

## Решение
Validation Engine проверяет качество цифровой модели: позиции, дубли, единицы измерения, уверенность и привязку. Он не формирует вывод о соответствии проектных решений нормативам.

Инженерные замечания формирует Rule Engine на основании подключённых каталогов правил.
