# Quality Core + Normative Intelligence 2.0

Реализовано:
1. Object Type Profiles: тип объекта определяет ожидаемые ТЭП и профильные разделы.
2. Engineering Verification 2.0: confidence рассчитывается по доказательствам, а не по уверенности AI.
3. Normative Intelligence 2.0: реестр документов, требования, применимость, статус верификации, evidence chain.
4. Неверифицированная нормативная ссылка не превращается в категоричный вывод.
5. Checklist Compiler распознаёт проверки обязательных документов и структуры ПД по ПП №87.
6. Межраздельный движок получает объектный профиль и нормативный контекст.

Важно: нормативная база намеренно не заполнена вымышленными номерами пунктов. Для production следующий этап — загрузка и постатейная верификация официальных текстов НТД.
