# ExpertCheck 9.5 Alpha 1 — Project Understanding

Главная цель версии — повысить качество понимания проекта, не увеличивая число самостоятельных функций.

## Project Understanding Engine 4.0
Формируется единая инженерная модель:
`объект → показатель → значение → единица измерения → раздел → документ → страница`.

Правила:
- инженерный показатель не может создать объект;
- показатель привязывается только к объекту из подтверждённого реестра;
- позиция генплана — сильный идентификатор;
- без позиции допускается только однозначная объектная привязка;
- неоднозначная привязка остаётся unresolved;
- unresolved-сведения не должны использоваться как доказательство межраздельного расхождения;
- для каждого параметра фиксируются разделы-источники, число доказательств, наличие профильного источника и конфликт значений.

## Интерфейс
Добавлена вкладка «Модель проекта»:
- количество объектов;
- сколько объектов получили характеристики;
- число неразрешённых привязок;
- индикатор качества привязки;
- таблица «объект → показатель → разделы → доказательства → конфликт».

## Межраздельная проверка
После построения Project Understanding выполняется финальный high-trust проход межраздельной сверки. Он использует уже размеченные объектно-параметрические связи.

## Отчёты
В Отчёт ГИПа и Техническое приложение добавляется лист «Модель проекта». В сводку добавлены показатели качества понимания проекта.

## Принцип безопасности
Лучше вернуть «недостаточно данных / неоднозначная привязка», чем сформировать ложное инженерное несоответствие.
