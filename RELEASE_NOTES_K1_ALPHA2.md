# ExpertCheck Studio 2.1 Alpha 2 / Knowledge Engine 1.0 Alpha 2

## Основные изменения
- строгая фильтрация файлов и строк перечня документов на двух уровнях: реестр и консолидация;
- универсальный структурный извлекатель перечней объектов без привязки к отраслевому словарю;
- неизвестные нефтегазовые объекты могут подтверждаться инженерным контекстом и двумя разделами;
- расширено извлечение ТЭП: давление, температура, диаметр, протяжённость, расход, напряжение, глубина;
- расширена межраздельная сверка новых характеристик;
- обновлены библиотеки объектов и характеристик нефтегазового профиля.
