# ExpertCheck 9.8 Alpha 2 — Drawing Intelligence 2.0

## Цель
Перевести графические разделы из режима «OCR/поиск текста» в доказательную модель чертежа: том → объект → лист → зона → локальная сущность → показатель → значение → источник.

## Реализовано
- Sheet/Object Graph по ведомости документов графической части и основным надписям.
- Title Block Ownership: владелец листа определяется по основной надписи; неоднозначная привязка удерживается.
- Room Schedule Parser: экспликации помещений читаются по строкам, с номером, наименованием, площадью и категорией.
- Semantic Scope Guard: AREA_ROOM и AREA_ROOM_SUM никогда автоматически не приравниваются к AREA_TOTAL/AREA_BUILD.
- Проверка арифметики строки «Итого» относительно суммы распознанных помещений.
- Physical provenance: для ключевых зон сохраняется bbox, если доступен PyMuPDF.
- Revision Graph alpha: извлекаются разрешения на изменения и привязка к объектным обозначениям.
- Golden Drawing Set: контрольные кейсы АР2 4.12, 4.13, 4.16, 4.5.
- В существующей Модели понимания проекта добавлена компактная диагностика чертежей без новой страницы.

## Архитектурный принцип
AI в следующих итерациях должен оркестрировать специализированные инструменты, а не самостоятельно угадывать владельца числа. Неоднозначный binding → WITHHOLD, а не ближайший текст.
