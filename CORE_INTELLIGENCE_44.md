# ExpertCheck 4.4 Alpha 1

## Strict Object Registry
- автоматическое включение только объектов со статусом trusted;
- жёсткая блокировка файлов, шифров, заголовков разделов, характеристик и текстовых требований;
- официальный источник + позиция как основной критерий;
- безпозиционный объект требует официальный источник и второе независимое подтверждение;
- одиночные текстовые и инженерные упоминания остаются кандидатами.

## Checklist Engine 3.0
- проверка выбранного чек-листа по выбранным документам;
- понимание иерархии пунктов и группирующих заголовков;
- автоматические ответы только при структурированных доказательствах;
- компактный результат из двух столбцов: позиция и соответствие;
