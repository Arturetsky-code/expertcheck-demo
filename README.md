# ExpertCheck Core 2.2 Alpha 2

## Основное изменение

Добавлен Object Register Engine 2.0 для более полного извлечения перечня объектов из многостраничных таблиц ПЗ.

### Исправлено

- позиции по генплану больше не ограничены веткой `4.x`; поддерживаются `2.1`, `2.1.1`, `12.3.4` и другие иерархические обозначения;
- коды классификатора вида `08.04.099.099` не принимаются за позиции по генплану;
- родительская и вложенная позиции сохраняются как разные объекты;
- добавлена колонка «Родительская позиция»;
- количество `3 шт.` извлекается из строки таблицы и учитывается в показателе физических объектов;
- многостраничные таблицы продолжают обрабатываться постранично, а дубли из разных таблиц объединяются по точной позиции.

### Проверка на ККВ

На ПЗ карты кучного выщелачивания тестовый прогон извлекает 11 уникальных реестровых позиций вместо двух, включая `2.1.1`–`2.1.6`, `2.2`, `2.3`, `2.4` и `2.4.1`.

## Sprint 1 Alpha 1 — Реестр объектов и Инспектор

Добавлен самостоятельный `Object Register Engine 3.0` (`core/object_register_engine.py`).

Ключевые изменения:
- точная позиция по генплану используется как первичный ключ;
- родительские и дочерние позиции не объединяются;
- безпозиционные находки присоединяются только при однозначном совпадении;
- ПЗ имеет максимальный приоритет как источник официального реестра;
- для каждой записи рассчитываются статус подтверждения и приоритет источника;
- в Studio появился режим «Инспектор реестра» с журналом принятых и отклонённых кандидатов.
