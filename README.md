# ExpertCheck Demo Cloud v0.1

Экспериментальная облачная версия сервиса предэкспертной проверки проектной документации.

## Возможности

- загрузка нескольких PDF;
- определение типа раздела ПД;
- извлечение первых ключевых показателей;
- упрощённая привязка показателя к объекту;
- межраздельное сравнение;
- выгрузка результатов в Excel.

## Быстрая публикация в Streamlit Community Cloud

1. Создайте на GitHub новый репозиторий, например `expertcheck-demo`.
2. Загрузите в корень репозитория все файлы и папки из этого архива.
3. Откройте Streamlit Community Cloud и выберите создание нового приложения.
4. Укажите ваш репозиторий, ветку `main` и файл запуска `app.py`.
5. Нажмите Deploy.

После развёртывания появится адрес вида `https://<название>.streamlit.app`.

## Локальная проверка перед публикацией

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

## Конфиденциальность

Файлы не записываются в репозиторий и не сохраняются приложением в постоянной базе. Однако при облачном использовании они передаются на инфраструктуру хостинга для обработки. Не загружайте конфиденциальную проектную документацию без разрешения владельца информации.
