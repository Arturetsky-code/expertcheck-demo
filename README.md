# ExpertCheck Core 2.1 Alpha 1

Переходная облачная сборка с цифровой инженерной моделью проекта (DEM).

## Новые компоненты

- `core/dem.py` — DEM Builder: объекты, характеристики и происхождение значений.
- `core/validation.py` — Validation Engine: качество и полнота модели.
- `core/relations.py` — Relation Engine: доказуемые структурные связи объектов.
- `core/model_quality.py` — индекс качества цифровой модели.
- `docs/adl/` — журнал архитектурных решений.

## Важно

Индекс качества DEM не означает готовность проектной документации к экспертизе. Он показывает, насколько полно и надёжно система смогла построить цифровую модель из загруженных документов.

## Обновление Streamlit Cloud

Загрузите содержимое этой папки в корень GitHub-репозитория. Основной файл: `app.py`.
