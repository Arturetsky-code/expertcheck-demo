# ExpertCheck 5.2 Alpha 1.1 — Resource Stability Hotfix

- `find_tables()` запускается только на страницах, классифицированных как официальный реестр объектов или таблица ТЭП.
- Этап формирования реестра разбит на подэтапы 52/57/62/66/72%, чтобы было видно фактическое место обработки.
- Ошибка одного дополнительного извлекателя больше не завершает весь анализ; она записывается в `pipeline_errors`.
- Таймауты внешних AI-провайдеров сокращены, чтобы зависший API не удерживал Streamlit-сессию.
- Служебные, графические и обычные текстовые страницы не передаются в тяжёлый табличный анализ.
