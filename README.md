# ExpertCheck Studio 1.0 Alpha 1

Новая рабочая оболочка ExpertCheck с упрощённой навигацией, инженерным дизайном и разделением рабочего/аналитического режимов. Ядро анализа сохранено на уровне Core 3.0 Alpha 4.

## Основные страницы
- Обзор
- Документы
- Объекты
- Сверки
- Замечания

## Запуск
```bash
streamlit run app.py
```
