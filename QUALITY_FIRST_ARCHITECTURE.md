# ExpertCheck 4.0 — Quality First Architecture

## Основной процесс

1. Пользователь загружает документы.
2. Project Engine формирует кандидатов объектов.
3. Пользователь исключает лишние позиции и подтверждает Trusted Object Registry.
4. CrossCheck Engine получает только подтверждённый реестр и сравнивает ТЭП конкретных объектов.
5. Checklist Engine работает независимо: пользователь выбирает чек-лист, раздел и конкретные документы.

## Quality Gate

Межраздельная сверка и замечания по ТЭП блокируются, пока пользователь не подтвердил состав проектируемых объектов.

## Рабочие пространства

- Проект
- Объекты
- Межраздельная сверка
- Чек-листы
- Замечания
- Отчёты
- Настройки
