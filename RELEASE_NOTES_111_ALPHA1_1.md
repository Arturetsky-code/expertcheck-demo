# ExpertCheck 11.1 Alpha 1.1 — Resource-Stable Confirmation Hotfix

## Причина сбоя

После подтверждения комплектности и состава объектов Streamlit Cloud завершал процесс по лимиту памяти. Поэтому Python traceback в журнале не было: платформа фиксировала только `connection reset by peer` на `/healthz`.

На контрольном комплекте из 12 PDF исходный снимок составлял около 586 МБ JSON, а пик RSS при автосохранении достигал около 3,18 ГБ.

## Исправления

- Глобальные графы доказательств, чек-листы, атомарные условия и модель проекта хранятся один раз в первой записи документа, а не дублируются для каждого тома.
- Сигнатура автосохранения больше не сериализует весь результат на каждом rerun.
- JSON сжимается в gzip потоково, без промежуточной полноразмерной копии.
- Восстановление снимка также выполняется потоково.

## Инварианты качества

Исправление не меняет Evidence Contract V2, Semantic Verdict Gate, fail-closed логику и четыре класса результа. `NOT_FOUND` по-прежнему не считается нарушением.
