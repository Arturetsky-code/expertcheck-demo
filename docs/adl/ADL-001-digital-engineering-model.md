# ADL-001: Цифровая инженерная модель как центральная сущность

## Проблема
Результаты извлечения из PDF недостаточны для устойчивой межраздельной проверки: одно значение может иметь несколько источников, а наименование объекта — несколько вариантов.

## Решение
Core 2.1 формирует Digital Engineering Model (DEM). PDF остаётся источником доказательств, а Rule Engine работает с объектами, значениями и их происхождением внутри DEM.

## Последствия
- Каждое значение сохраняет документ, страницу, метод извлечения и уверенность.
- Непривязанные характеристики не считаются подтверждёнными.
- Отраслевые ожидания и связи не зашиваются в код и должны поступать из Knowledge Packs.
