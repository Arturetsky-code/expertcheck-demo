# ExpertCheck 10.1 Alpha 1 — Review Planner & Verification Core

## Ключевое изменение архитектуры
ExpertCheck переходит от набора параллельных анализаторов к единому циклу инженерной проверки:

`Понимание проекта → План проверки → Доказательства → Верификация → Квалификация результата → Отчёт`.

Центральные контуры проверки:
1. соответствие Заданию на проектирование;
2. соответствие требованиям НТД;
3. корпоративные чек-листы.

Межраздельная сверка, Drawing Intelligence, Project Knowledge Graph и AI становятся инструментами этих трёх контуров, а не отдельными пользовательскими продуктами.

## Упрощение интерфейса
В обычном режиме осталось четыре рабочих экрана:
- Проект;
- Проверка;
- Результаты;
- Отчёт.

Старые детальные страницы доступны в режиме разработчика.

## Project Review Planner
Для каждого проекта строится программа проверок и отдельно рассчитывается доказательное покрытие Задания, НТД и чек-листов. Проверка считается завершённой только при подтверждённом соответствии или доказанном несоответствии.

## Verification Core
Единая классификация:
- Соответствует;
- Выявлено несоответствие;
- Требует проверки специалистом;
- Не проверено автоматически.

Ограничение ExpertCheck не является замечанием к проекту.

## Checklist Verification
Каждый пункт теперь получает `proof_kind`. Структурированное значение/сверка могут завершить автоматическую проверку. Тематический фрагмент остаётся кандидатом. Отсутствие надёжного алгоритма даёт «Не проверено автоматически», а не псевдозамечание.

## Отчёты
Основные XLSX сокращены:
- резюме руководителя: итог + ключевые выводы + действия;
- отчёт ГИПа: резюме + квалифицированные результаты + контроль соответствия + план действий;
- технические массивы остаются только в техническом приложении.
