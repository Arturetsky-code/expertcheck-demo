# ExpertCheck 15.2.1 — Coverage Acceleration & Reliability

## Цель

Ускорить рост покрытия без ослабления доказательной политики: слабое совпадение по-прежнему не становится выводом.

## Изменения

- невалидный JSON от AI теперь запускает резервного провайдера;
- OpenRouter получает `response_format=json_object`, когда контракт требует JSON;
- «Расширенная» проверка охватывает весь практический L4-корпус; очередь чередуется по семействам checker-ов;
- L5-результат, `adversarial_state` и контракт доказательств согласованы в одном итоговом состоянии;
- вопрос 500/334,86 содержит оба значения, смысловые уровни, документ и страницу;
- все `HOLD/REJECT`-дубли явно исключаются из межраздельных сравнений;
- 25 м для насосной сохраняются как исходное значение; 2,5 м показываются только как гипотеза для проверки специалистом.

## Политика безопасности

`NOT_FOUND` не является нарушением. AI-ответ без допустимых `evidence_id`, независимого Critic и пройденного локального gate не может повысить результат до L5.

## Контроль выпуска

Команда `python -B tools/validate_1521.py` запускает наследованный release gate 15.2 и новые regression-сценарии 15.2.1. Более широкий совместимый набор можно прогонять обычным `pytest`, когда доступны исходные PDF-фикстуры.
