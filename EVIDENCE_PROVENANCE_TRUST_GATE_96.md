# ExpertCheck 9.6 Alpha 1 — Evidence Provenance & Trust Gate

## Цель
Повысить достоверность инженерной проверки без расширения количества функций.
Главное правило версии: уверенность извлекателя не равна доказанности привязки значения к объекту.

## Что добавлено
Для каждого инженерного факта формируется паспорт происхождения (`evidence_provenance`):
- стабильный `evidence_id`;
- документ и страница;
- объект и показатель;
- структурный способ извлечения;
- статус привязки к строке/позиции;
- результат Table Row Integrity Guard;
- deterministic trust score 0–100;
- grade A/B/C/D;
- решение VERIFIED / SUPPORTED / HOLD / REJECT;
- отдельные флаги допуска в сравнение и допуска к формированию mismatch.

## Ключевое ограничение
Высокий AI/extractor confidence сам по себе больше не считается достаточным основанием для инженерного расхождения.
Для mismatch требуется структурное доказательство: row lock, подтверждённая строка, позиция по ГП или структурированный источник.

## Поведение
- VERIFIED/SUPPORTED могут участвовать в межраздельном сравнении;
- HOLD остаётся в диагностике, но не формирует замечание;
- REJECT исключается;
- Project Understanding сохраняет provenance-поля вместе с evidence.

## Regression
Добавлены тесты на случай, когда слабая generic-находка 23,5 м² конфликтует с двумя структурно подтверждёнными значениями 89,9 м². Итог должен оставаться `СОВПАДАЕТ`.
