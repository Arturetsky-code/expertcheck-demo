# ExpertCheck 9.8 Alpha 1 — Engineering Knowledge Core

## Главная цель
Версия переводит систему от схемы «нашёл данные → сравнил» к доказательному инженерному конвейеру. Новые функции интерфейса намеренно не добавлялись.

## 1. Fact Admission Gate 2.0
Перед включением значения в Project Understanding отдельно оцениваются:
- WHO — какому объекту принадлежит значение;
- WHAT — какой инженерный показатель найден;
- VALUE — валидность числового значения и единицы;
- WHERE — документ, страница и трассируемый источник.

Высокий confidence больше не компенсирует отсутствие доказанной принадлежности объекту. Результат gate: ADMIT / HOLD / REJECT.

## 2. Applicability Matrix 1.0
Межраздельная сверка больше не использует один плоский список ожидаемых разделов для любого объекта. Ожидаемые источники зависят от типа объекта и показателя. Матрица является универсальным базовым слоем и рассчитана на дальнейшие отраслевые профили.

## 3. Typed Checklist Engine 1.0
Чек-листы начинают маршрутизироваться по типу проверки:
- числовая инженерная сверка;
- наличие структурированных параметров;
- наличие чертежа/содержания;
- основная надпись;
- смысловая инженерная проверка;
- нормативная проверка;
- контроль специалиста.

Неудачный поиск ключевого слова больше не формирует отрицательный вывод. Если алгоритм не способен доказать отсутствие, статус — «Не проверено системой».

## 4. PP87 conservative evidence policy
Контрольная матрица ПП №87 больше не возвращает «Нет» только из-за отсутствия найденных ключевых слов. Такой случай переводится в «Не проверено системой».

## 5. Risk Admission tightening
Отрицательный результат чек-листа без конкретного доказательного источника не допускается в реестр рисков. AI может поднять вопрос, но не создать замечание без evidence.

## 6. Atomic Assignment Parser 2.0
Парсер Задания на проектирование:
- восстанавливает отдельные нумерованные строки;
- сохраняет номер исходной строки;
- дробит склеенные требования по сильным границам;
- помечает атомарные требования;
- поддерживает прямые числовые условия без обязательного глагола «предусмотреть».

## 7. Quality Benchmark foundation
Добавлен модуль объективной оценки релизов по golden projects:
- True Positive;
- False Positive;
- False Negative;
- Correct Abstention;
- Unsupported;
- Precision / Recall / F1.
