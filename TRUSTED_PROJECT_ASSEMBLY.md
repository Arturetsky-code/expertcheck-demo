# ExpertCheck Studio 3.1 Alpha 2 / Core Quality 5.0

## Trusted Project Assembly

1. После анализа система формирует единый список кандидатов объектов.
2. Пользователь вручную включает или исключает позиции.
3. До подтверждения перечня реестр, паспорта объектов и межраздельные сверки не публикуются.
4. После подтверждения сравнения фильтруются только по выбранным объектам.
5. Изменение перечня автоматически отменяет прежнее подтверждение.

## Checklist Engine 2.0

Проверка запускается вручную по цепочке:

`Раздел ПД -> соответствующий чек-лист -> режим проверки -> запуск`.

Режимы:
- Быстрая: пункты A.
- Полная: пункты A и B.
- Экспертная: пункты A, B и C.

Ручные пункты не считаются выполненными без решения пользователя.
